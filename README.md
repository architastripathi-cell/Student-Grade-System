# 🎓 Student Grade System

A simple **Java-based Student Grade System** that takes student details and marks in Java, Python, and C, then calculates the **total marks, percentage, and grade**.

## 📌 Project Description

The Student Grade System is a console-based Java application designed to calculate a student's academic performance.

The program accepts:

* Student Name
* Roll Number
* Java Marks
* Python Marks
* C Marks

It then calculates the **total marks and percentage** and assigns a grade based on the percentage obtained.

## ✨ Features

* 🧑‍🎓 Takes student name as input
* 🔢 Takes roll number
* 💻 Accepts marks for Java, Python, and C
* ➕ Calculates total marks
* 📊 Calculates percentage
* 🏆 Assigns grade automatically
* 📋 Displays complete student details
* 🔒 Properly closes the Scanner resource

## 🛠️ Technologies Used

* **Java**
* **Scanner Class**
* **Variables & Data Types**
* **Arithmetic Operators**
* **Conditional Statements**
* **Object-Oriented Programming (OOP)**

## 📈 Grading System

| Percentage    | Grade |
| ------------- | ----- |
| 90% and above | A     |
| 80% – 89%     | B     |
| 60% – 79%     | C     |
| Below 60%     | D     |

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone <your-repository-link>
```

### 2. Open the Project

Open the project in any Java-supported IDE such as:

* IntelliJ IDEA
* Eclipse
* NetBeans
* VS Code

### 3. Compile the Program

```bash
javac StudentGradeSystem.java
```

### 4. Run the Program

```bash
java StudentGradeSystem
```
